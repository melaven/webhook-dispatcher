## 🔧 Troubleshooting

### Проблема: ImportError
**Решение:** Убедитесь что виртуальное окружение активно и зависимости установлены
```bash
venv\Scripts\activate
pip install -r requirements.txt
```

### Проблема: Connection refused
**Решение:** Запустите сервер в отдельном терминале
```bash
python main.py
```

### Проблема: 403 Forbidden в успешных тестах
**Решение:** Проверьте API ключ в .env файле
```bash
# Содержимое .env
DISPATCHER_API_KEY=dev-webhook-dispatcher-key-2024
WEBHOOK_SECRET=dev-hmac-secret-for-webhook-validation
```

## 📊 Метрики успешности

- **100% тестов** должны проходить успешно
- **Все эндпоинты** должны корректно обрабатывать авторизацию
- **База данных** должна сохранять все запросы
- **Валидация** должна отклонять некорректные данные

## 🎬 Демонстрационные curl команды

После успешных тестов используйте сгенерированные curl команды:

```bash
# Защищенный запрос лида
curl -X POST "http://localhost:8000/api/v1/webhook/incoming" \
     -H "Content-Type: application/json" \
     -H "X-API-Key: dev-webhook-dispatcher-key-2024" \
     -d '{"event_type": "lead.created", "source": "demo", "data": {"name": "Demo User", "phone": "+7999999999"}}'

# Получение статистики
curl -X GET "http://localhost:8000/api/v1/stats" \
     -H "X-API-Key: dev-webhook-dispatcher-key-2024"

# Тест без авторизации (вернет 403)
curl -X POST "http://localhost:8000/api/v1/webhook/incoming" \
     -H "Content-Type: application/json" \
     -d '{"event_type": "test"}'
```
